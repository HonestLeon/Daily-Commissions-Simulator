# 前端 UI 设计审查报告（轻量便签）

> 基于对 `src/components/TitleBar.tsx`、`Sidebar.tsx`、`NoteEditor.tsx`、`LixingDialog.tsx`、`SettingsPanel.tsx` 与 `src/App.css`（约 1440 行）的实际代码审查。**可量化事实**与**设计判断**分开标注。评审日期：本报告随代码审查生成，仅评审、未改动代码。

## 总体判断

底子不错：间距有 8px 节拍、圆角（6/8/12px）和阴影系统基本统一，半透明面板 + Acrylic 方向正确，深/浅双主题覆盖完整。主要问题集中在**视觉一致性、对比度、可发现性与无障碍**，以及若干**遗留死代码造成的 UX 缺口**。

---

## 一、视觉一致性（中优先——影响整体品质感）

| # | 问题 | 类型 | 位置 |
|---|---|---|---|
| 1 | **标题栏图标"三套系统"混用**：PNG 图标（`app-icon/lixing/yuan-shi`）、Emoji（`📌 ⏰ ⭕ 🔄 ⚙`）、文本字形（`─ ✕`）。Emoji 在不同 Windows 上渲染为彩色/描边/纯文本不一，且与精致 PNG 图标风格不匹配，是整体最明显的"廉价感"来源。 | 事实 | `TitleBar.tsx` |
| 2 | 三个面板用了**三种不同的"白"**：标题栏 `rgba(245,…)`、侧边栏 `rgba(243,244,246,…)`、编辑区 `rgba(255,…)`，透明度 0.6/0.5/0.72 各不相同 → 无皮肤时桌面透过来的亮度不均，玻璃质感不统一。 | 事实 | `App.css` `.titlebar` / `.sidebar` / `.editor-area` |
| 3 | `text-transform: uppercase` 用在中文"委托列表"上**无效**（CJK 无大小写），属于死样式。 | 事实 | `App.css` `.sidebar-title` |
| 4 | 字号碎片化：正文 13-15px、标签/日期/计数 10/11/12px 散落各处，无明确的类型层级；10px 的计数/角标在低透明度下几乎看不清。 | 事实 | `App.css` 各组件 |
| 5 | 部分组件内联 style 与 class 混用（`LixingDialog.tsx`），与 settings 的手写样式重复，缺乏 token 化。 | 事实 | `LixingDialog.tsx` |

## 二、对比度与可读性（高优先——无障碍/清晰度）

| # | 问题 | 类型 | 位置 |
|---|---|---|---|
| 6 | 大量**低对比度文字**：日期/描述/占位符用 `#999/#888/#777`，白底上的 `#999` 对比度约 **2.4:1**，远低于 WCAG 正文 4.5:1 与大字 3:1；叠加面板半透明后实际更低。 | 事实 | `App.css` 日期/描述/占位符 |
| 7 | 编辑器相关次要文本、内联代码 `#d63384` 等在透明前景下对比一般；暗色下 `#888/#aaa` 同样偏低。 | 事实 | `App.css` `.ProseMirror` |
| 8 | 皮肤开启只降低面板透明度让背景可见，但**未同步增强前景对比**；皮肤图为中亮色时前景文字可能落入低对比区。 | 设计判断 | 皮肤相关 CSS |

**建议方向**：把浅/深两套"次要文本色"统一定义为满足 4.5:1 的 token，并在皮肤或背景图下方自动加深前景色（叠加一层蒙版）。

## 三、可用性与可发现性（高优先）

| # | 问题 | 类型 | 位置 |

## 四、玻璃/Acrylic 效果的真实性（设计判断）

窗口是 `transparent`，面板与弹窗的 `backdrop-filter: blur(30px)` **只会模糊页面内内容，模糊不了窗口背后的桌面**。因此"磨砂玻璃"实际观感是半透明白板而非真正毛玻璃。要么接受这种"亚克力白"，要么弱化 blur 的期待。

---

## 五、皮肤系统与主题（设计判断）

- 皮肤定位合理（整窗背景 + 半透明面板在上），但面板透明度（标题 0.35 / 侧栏 0.3 / 编辑 0.45）**三块不一致**，图透出强度参差。
- 建议给皮肤统一"内容蒙版层"（同一暗化/提亮系数），保证任意背景图上前景都可读。

---

## 六、性能（事实）

- 编辑大包：单一 chunk `1,731 kB`（gzip `548 kB`），来自 Crepe 全家桶，启动首屏解析较大，属性能隐患（非纯视觉）。

---

## 优先级汇总（建议改进顺序）

1. **高**：对比度体系化（#6/8）、恢复"新建"入口（#9）、键盘焦点/无障碍（#10/11）。
2. **中**：统一标题栏图标为一套 SVG/PNG 并加 aria-label（#1）、统一面板表面的白与透明度（#2）、整理解死样式与字号层级（#3/4）。
3. **低**：菜单越界/Escape（#14）、把透明度移入设置（#13）、皮肤统一蒙版。
