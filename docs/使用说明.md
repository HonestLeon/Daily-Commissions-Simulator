# 每日委托模拟器 · 使用说明

> 一款半透明 Acrylic 材质的 Markdown 桌面便签，用「每日委托 + 原石 + 摩拉」把每天的任务变成看得见的积累。

![主界面](assets/01-主界面.png)

---

## 1. 安装与启动

发布包内提供两种版本，按需选用其一：

| 版本     | 文件                                    | 适用场景                                               |
| -------- | --------------------------------------- | ------------------------------------------------------ |
| 安装版   | `每日委托模拟器_x.x.x_x64-setup.exe`    | 常规使用。双击安装，支持开机自启与「检查更新」一键升级 |
| 免安装版 | `每日委托模拟器_x.x.x_x64-portable.exe` | 绿色版，单文件即开即用，可放 U 盘随身携带              |

- 安装版：双击 setup.exe，按向导完成安装后从开始菜单或桌面快捷方式启动。
- 免安装版：双击 exe 直接运行，无需任何依赖。
- 首次启动较慢属正常现象（Windows Defender 首次扫描），后续启动会明显加快。

## 2. 界面总览

应用分为三个区域：

- **标题栏**：左侧为应用图标（点击可打开 Gitee 仓库）、原石与摩拉余额；右侧从左到右依次为「砺行修远」「置顶模式」「检查更新」「设置」「最小化」「关闭」按钮。
- **委托列表（侧边栏）**：按日期倒序展示每天的委托便签，点击切换，双击标题可重命名，右键提供重命名 / 删除菜单。
- **编辑区**：所见即所得的 Markdown 编辑器，内容即为标准 Markdown 文本。

开启桌宠模式后（见第 9 节），同一个窗口会有两种形态：**便签态**就是上面这三区；**宠物态**只剩一只桌面小宠物，便签内容原封不动地收在后面。

![每日委托](assets/02-每日委托.png)

## 3. 每日委托

应用每天自动创建一份「每日委托」便签，固定结构为：

| 模块      | 说明                   | 是否参与结算 |
| --------- | ---------------------- | ------------ |
| 必做      | 当天必须完成的核心事项 | 是           |
| 学习/工作 | 学习与工作类任务       | 是           |
| 生活/其他 | 生活琐事与其他安排     | 是           |
| 随手小记  | 自由记录区，不参与结算 | 否           |

**智能继承**：第二天创建新委托时，前一天**未完成**的任务会自动带入今天，已完成的不再出现，无需手动誊抄。

## 4. 明日委托

想为明天预定任务？在「学习/工作」「生活/其他」模块内写下一行任务后，行末会出现「明日委托」勾选小按钮：

![明日委托](assets/03-明日委托.png)

勾选后该行变为引用块（`> ` 前缀），当天**不参与结算**；明天创建新委托时，它会自动转为当天的待办任务。

> 提示：勾选框只在光标不在该行内时显示，输入完成后点击其他位置即可看到。

## 5. 原石与摩拉

每日委托在次日首次启动时自动结算，两种货币的规则不同：

| 货币    | 结算规则                                               |
| ------- | ------------------------------------------------------ |
| ⭐ 原石 | 按完成的模块数计：1 个模块 +10，2 个 +20，三全完成 +50 |
| 🪙 摩拉 | 三个结算模块内「已勾选且非空」的任务条数 × 100         |

**模块完成的判定**：该模块内至少有一条非空委托，且所有非空委托全部勾选。空着的委托不算完成——所以请认真填写并做完当天的委托，空的模块得不到任何奖励。

结算后标题栏会弹出土司提示（如「前日委托已结算：+50 原石 +800 摩拉（三全完成）」）。

## 6. 砺行修远（周挑战）

点击标题栏「砺行修远」按钮查看本周战绩：

![砺行修远](assets/08-砺行修远.png)

- **规则**：一个自然周内 ≥ 5 天「三全完成」委托，即达成挑战，获得 100 × 连续周数 的原石奖励。
- 连续达成的周数越多，奖励越高；某周未达标则连续周数清零，但本周仍可补做后再次结算。
- 每个自然周只结算一次，达标发奖后本周即锁定。

设置 → 皮肤 → 「导入 / 更换」，选择一张图片（PNG / JPG / WebP，≤ 8MB）作为整窗背景。皮肤层位于内容之下，蒙版颜色随当前主题色调变化，不影响文字阅读；点「移除皮肤」即可恢复默认背景。

## 8. 窗口控制

### 置顶模式（三态循环）

点击标题栏「置顶」按钮，或使用 `Ctrl + Shift + T`，在三种模式间循环切换：

| 模式     | 表现                                                 |
| -------- | ---------------------------------------------------- |
| 普通模式 | 常规窗口                                             |
| 始终置顶 | 窗口始终保持在其他窗口之上，工作时可见但不遮挡       |
| 闹钟模式 | 每隔设定间隔自动弹出置顶提醒，显示设定时长后自动隐藏 |

### 闹钟模式参数

设置 → 闹钟提醒：

- **提醒间隔**：每隔多少分钟弹出一次（最小 1 分钟）。
- **显示时长**：每次弹出后置顶显示多少秒（最长 60 秒）。
- 首轮提醒在开启后 1 分钟触发；提醒结束后按「关闭行为」设置隐藏到托盘或最小化到任务栏。

### 透明度

设置 → 显示 → 透明度滑块，或使用 `Ctrl + =` / `Ctrl + -` 步进调节（25% ~ 100%），窗口、面板、皮肤整体联动。

## 9. 桌宠形态

便签与桌宠是**同一个窗口的两种形态**：编辑器不会重载，内容始终同源。

![宠物态](assets/10-桌宠-宠物态.png)

### 开启与关闭

| 入口                   | 说明                                                      |
| ---------------------- | --------------------------------------------------------- |
| 托盘右键 → 桌宠模式    | 立即生效，并在屏幕上显示宠物                              |
| 设置 → 桌宠 → 桌宠模式 | 同上；关闭后应用行为与桌宠化之前完全一致                  |
| `Ctrl + Shift + P`     | 便签 ⇄ 桌宠切换。**只有便签态有效**（宠物态不抢键盘焦点） |

### 怎么用

- **展开便签**：单击宠物。
- **移动宠物**：按住拖动（位移超过 4 像素才算拖拽，否则算单击）；靠近屏幕边缘会自动吸附。
- **缩回宠物**：鼠标移出便签窗口约半秒后自动收起；也可以按 `Ctrl + Shift + P`。正在打字或有未保存改动时**不会**收起，不会打断你。
- **拖动便签不算「移开」**：按住标题栏把便签窗拖到别处，鼠标一路滑出窗外也不会误缩成宠物——只有真正松手离开才收。
- **她的窗没有边框**：宠物态去掉了可见边框与投影，并被锁成不可拉伸。想改大小只能去「设置 → 桌宠 → 宠物大小」，因为窗口就是宠物可见轮廓的外框，用边框硬拉等于把桌面上「点不动」的一圈透明区一起拉大。切回便签态后窗口照常可自由拉伸（最小 340×300 逻辑像素）。**已知问题**：便签态拖边框调整大小时，她会把这个动作误判成「鼠标移开」而缩成宠物，有时还会缩成一只便签那么大的——单击它就展开了，这一条下一版修掉。

### 她会看你的数据

| 触发                    | 表现                             |
| ----------------------- | -------------------------------- |
| 三个模块全部完成        | 庆祝类动作 + 气泡报原石/摩拉增量 |
| 委托还没做完            | 垂头叹气                         |
| 「明日委托」没填        | 心虚的小动作 + 气泡提醒          |
| 深夜（23:00–08:00）     | 犯困、小憩                       |
| 工作时间（09:00–19:00） | 写字干活                         |
| 清晨（06:00–09:00）     | 晨间刷牙                         |

### 说话的分寸

![气泡](assets/11-桌宠-气泡.png)

- 气泡是一条**独立的透明小窗**，逐字浮现（约每秒 28 字），点一下即关闭。
- 只在**主人空闲 8 秒 ~ 10 分钟**之间开口：正在敲键盘时不吵你，离开太久这句就不说了。
- 宠物隐藏时（收进托盘、让路全屏）不会说话，动画也一并暂停。

### 可调节项（设置 → 桌宠）

![设置-桌宠](assets/12-设置-桌宠.png)

- **宠物大小**：50% ~ 150%。窗口就是宠物可见轮廓的外框，放大它等于放大桌面上「点不动」的一圈区域，因此上限收在 150%。
- **动作间隔**：很频繁（15~30 s）→ 频繁（30~60 s）→ 标准（45~90 s）→ 悠闲（60~120 s）→ 安静（120~180 s）→ 很安静（180~300 s）六档，实际时长在区间内随机（固定间隔会被摸出规律，变成闹钟）。
- **安静档还会慢放**：选到「安静」或「很安静」时，常驻的呼吸动画慢放一倍，整只宠物明显沉静下来。叹气、哼歌、写字、刷牙这类一次性动作演完就回到呼吸，不会首尾相接循环。
- **缩回宽限**：鼠标移出多久自动收成宠物，毫秒；填 0 = 不自动缩回，只靠快捷键或托盘。
- **他人全屏时让路**：检测到游戏 / 投屏 / 全屏播放时整只宠物隐身，退出后回到原位。

## 10. 系统托盘与开机自启

- **关闭行为**：首次点击关闭按钮会弹窗询问「最小化到托盘」或「直接退出」，选择后记住。之后关闭窗口默认进托盘，应用在后台常驻。
- **唤回窗口**：单击托盘图标即可唤回，右键菜单为「显示窗口 / 桌宠模式：开·关 / 开机自启：开·关 / 退出」。即使窗口先前是最小化状态（点了标题栏的 `─`）也一样叫得回来。
- **开机自启**：设置中开启后，登录 Windows 自动启动并最小化到托盘。

## 12. 快捷键

| 快捷键                  | 功能                               |
| ----------------------- | ---------------------------------- |
| `Ctrl + ,`              | 打开设置                           |
| `Ctrl + =` / `Ctrl + -` | 增加 / 降低窗口透明度              |
| `Ctrl + Shift + T`      | 切换置顶模式（普通 → 置顶 → 闹钟） |
| `Ctrl + Shift + P`      | 便签 ⇄ 桌宠切换（仅便签态有效）    |
| `Alt + F4`              | 关闭窗口（按关闭行为处理）         |

> 宠物态的窗口不吃键盘焦点（否则会把焦点从你正在打字的地方抢走），所以快捷键在宠物态收不到；展开便签请单击宠物或用托盘菜单。

## 13. 编辑器说明

编辑器基于 Milkdown（所见即所得），同时支持标准 Markdown 语法：

- 任务列表：`- [ ] 任务` / `- [x] 已完成`
- 明日委托：`> 任务内容`（引用块）
- 其他：标题 `#`、列表 `-`、加粗 `**`、斜体 `*`、代码、表格等标准语法均可使用
- 内容自动保存（输入后短暂延迟落盘），无需手动保存

## 14. 数据与备份

所有数据仅存储在本地，不上传任何信息：

```
%APPDATA%\com.liurr.lightweight-sticky-notes\
├── config.json          # 配置（原石 / 摩拉 / 主题 / 透明度 / 闹钟参数等）
├── notes_index.json     # 委托索引（含结算状态）
├── notes\<uuid>.md      # 每条委托的 Markdown 原文
└── skins\               # 皮肤图片
```

备份：复制整个上述文件夹到安全位置即可；恢复时粘贴回原路径。

## 15. 常见问题

**Q：绿色版首次启动慢？**
Windows Defender 首次扫描所致，属正常现象，后续启动更快。

**Q：当天什么都没做，会有奖励吗？**
不会。空模块不算完成，原石与摩拉都为 0——这正是督促完成委托的机制。

**Q：明天的任务怎么提前记？**
写在「学习/工作」或「生活/其他」模块下，勾选行末的「明日委托」框即可（见第 4 节）。

**Q：换了电脑怎么迁移？**
备份 `%APPDATA%\com.liurr.lightweight-sticky-notes\` 整个文件夹，在新电脑粘贴回原路径（原石、摩拉与全部委托都会恢复）。

**Q：桌宠挡住了桌面图标 / 我点不到后面的东西？**
宠物窗口等于它身体的可见外框（默认约 175×221 逻辑像素），矩形四角确实点不穿——这是 Windows 上不做逐像素穿透的代价。把它拖到屏幕边或角落（会自动吸附），或在设置里调小「宠物大小」，再或临时用托盘关掉桌宠模式。

**Q：鼠标都移出便签了，她为什么还不缩回？**
两种情况是故意的：光标还停在正文里（她以为你在打字），或还有没落盘的编辑。点一下标题栏、侧边栏这类非编辑区让编辑器失焦，再移开鼠标就收了；实在想立刻收起来，按 `Ctrl + Shift + P` 或走托盘。

**Q：能拖着宠物的边框把她放大吗？**
不能。宠物态窗口无边框、无投影，也被锁成不可拉伸——一拉就等于把桌面上点不动的透明区一起拉大。尺寸请在「设置 → 桌宠 → 宠物大小」调（50%~150%）。切回便签态后窗口可自由拉伸。

**Q：宠物为什么半天不说话？**
它只在主人空闲 8 秒 ~ 10 分钟之间开口，且隐藏时不说。若一直感觉它「该说话时不说」，看第 9 节。

**Q：全屏打游戏 / 投屏时它会挡吗？**
不会。默认开启「他人全屏时让路」，检测到全屏应用就整只隐身，退出后回原位；不想要这个行为可在设置 → 桌宠里关掉。

**Q：能在 macOS / Linux 上运行吗？**
当前版本针对 Windows 打包与测试。
